Evidence first.

Working status

Board evidence applies to the stated modes and test patches. Native tests run on the development computer. “Not yet verified” means we have no qualifying result; it does not mean the object is broken.

Optimisation

Available means a reviewed compiler option exists for the stated forms. Experimental means the work is still private or awaiting admission. “No measured change” is not a claim that an object is already optimal.

CPU time saved

A reduction from the reference patch's processing time, measured on the board. Open a result for its cases, profiles and limits. Matching an identical module is a control, not an optimisation gain.

Test platform: Waveshare ESP32-S3 AMOLED 1.8 V2 · 44,100 Hz · 256-frame blocks. Offline measurements exclude I2S, the display and networking unless stated.
